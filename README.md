# 电缆绞合成缆结构设计与三维校验系统

中压电力电缆 / 控制电缆的绞合、成缆结构设计与三维校验工具。纯浏览器运行,
TypeScript + WebGL2(手写着色器,无三维框架),数据存 IndexedDB。

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 类型检查 + 生产构建
npm test           # 绞入系数/用量与手算对比测试(误差 ≤0.2%)
```

## 页面

| 页面 | 功能 |
|------|------|
| 电缆结构 | 从里往外建层(导体屏蔽/绝缘/绝缘屏蔽/金属屏蔽/内衬/铠装/护套),材料厚度可改,截面图实时绘制 |
| 导体绞合 | 逐层设根数/单线直径/节距比/绞向(相邻层默认反向),正规绞判定,层容纳根数校验,绞入系数与每公里用铜/铝量,圆形与扇形紧压 |
| 成缆排布 | 多芯+填充绳,节距/绞向/退扭切换,成缆绞入系数、单芯长度、自转圈数 |
| 三维校验 | 螺旋线扫掠 + 实例化渲染(每层一份网格,全层单线实例化),任意位置横切,压入标红/悬空标黄,成缆与铠装(钢带搭盖/钢丝)三维显示 |
| 截面分析 | 8 方向厚度录入 → 最薄点/偏心度,外径公差判定,扇形芯不退扭挤偏风险区,实测照片导入对齐叠加、根数与外径偏差统计 |
| 工艺单 | 每层节距/绞向/牵引速度/绞笼转速,导出文本工艺单与截面图 PNG |

## 核心公式(与手册一致)

- 绞入系数:`k = √(1 + (π·D/h)²) = √(1 + (π/m)²)`,D 为层节圆直径,h 为节距,m 为节距比
- 每公里单线长度:`k × 1000 m`;每公里金属重量:`A·n·k·1000·ρ·10⁻³` kg(A 单线截面 mm²,n 根数,ρ 密度 g/cm³)
- 层容纳根数:`n ≤ π / arcsin(d / (2R))`,R 为节圆半径
- 成缆节圆半径:n 芯均布 `R = r / sin(π/n)`
- 紧压:金属面积守恒,填充率 η = 金属面积 / 包络面积

`tests/` 中的用例把程序结果与上述手算式逐项对比,误差要求 ≤0.2%(实际为同式精度)。

## 存储

IndexedDB 数据库 `cable-designer`,三个表:`cables`(结构设计)、`measurements`(实测记录,含照片 dataURL 与对齐参数)、`process`(工艺参数)。
